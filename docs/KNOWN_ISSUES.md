# Known Issues and Limitations — Plasma SIP

## Current Open Issues
1. **Direct Hardware Verification Gate:** Physical AVM FRITZ!Box hardware verification requires local network access and provisioned IP phone credentials. In environments without physical test devices, automated SIP fixtures are used and hardware testing is documented as BLOCKED pending physical execution.
2. **Qt6 Build Headers:** System currently has runtime Qt 6 and Kirigami installed; header development packages (`qt6-qtbase-devel`, `qt6-qtdeclarative-devel`, `kf6-kirigami-devel`) may be required for C++ binding compilation in Milestone 7.
