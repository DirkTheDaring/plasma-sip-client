# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Plasma SIP**, please do **not** file a public GitHub issue.

Please report security issues responsibly through one of the following channels:
1. **GitHub Private Vulnerability Reporting:** Go to the [Security Advisories tab](https://github.com/plasma-sip/plasma-sip/security/advisories) and select **"Report a vulnerability"**.
2. **Email:** Contact the maintainers at `security@plasma-sip.org`.
